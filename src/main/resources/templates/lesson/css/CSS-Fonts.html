CSS Fonts

Choosing the right font has a huge impact on how a website is experienced by users.

CSS Font Families

In CSS, there are two types of font family names:

  • Generic family - a group of font families with a similar look (like "Serif" or "Monospace")
  • Font family - a specific font family (like "Times New Roman" or "Arial")

The font-family Property

The font-family property should hold several font names as a "fallback" system.

If the browser does not support the first font, it tries the next font, and so on.

Example:

Try it Yourself 
.p1 {
  font-family: "Times New Roman", Times, serif;
}

.p2 {
  font-family: Arial, Helvetica, sans-serif;
}

The font-style Property

The font-style property is mostly used to specify italic text.

Example:

Try it Yourself 
p.normal {
  font-style: normal;
}

p.italic {
  font-style: italic;
}

The font-size Property

The font-size property sets the size of the text.

Example:

Try it Yourself 
h1 {
  font-size: 40px;
}

h2 {
  font-size: 30px;
}

p {
  font-size: 14px;
}
