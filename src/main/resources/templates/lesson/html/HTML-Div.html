HTML The <div> Element

The <div> element is used as a container for other HTML elements.

The <div> Element

The <div> element is by default a block-level element, meaning that it takes up the entire width of the page, and it starts on a new line.

The <div> element has no required attributes, but style, class and id are common.

When used together with CSS, the <div> element can be used to style blocks of content:

Example:

Try it Yourself 
<div style="background-color:black;color:white;padding:20px;">
  <h2>London</h2>
  <p>London is the capital city of England.</p>
</div>

Center a <div> Element

To center a <div> element, you can use CSS to set the width and set the left and right margins to auto:

Example:

Try it Yourself 
<div style="width:300px;margin:auto;">
  <p>This div is centered.</p>
</div>
