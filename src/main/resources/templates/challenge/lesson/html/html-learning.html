HTML Introduction

What is HTML? HTML stands for HyperText Markup Language. It is not a programming language; rather, it is a markup language that defines the structure and meaning of your web content.

If building a website were like building a house, HTML would be the bricks and the structural frame. (CSS would be the paint and interior design, and JavaScript would be the electricity and plumbing).

The Anatomy of an HTML Element

Figure 1: Anatomy of a standard HTML element.

An HTML element is generally made up of a start tag, the content, and an end tag. Sometimes, tags also contain attributes that provide extra information about the element.

  • Opening tag: The name of the element wrapped in angle brackets (e.g., <p>).
  • Attributes: Placed inside the opening tag (e.g., class="text-bold").
  • Content: The text or other elements contained within the tags.
  • Closing tag: Marks where the element ends (e.g., </p>).

Example:

Try now 
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport"
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello HTML</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
