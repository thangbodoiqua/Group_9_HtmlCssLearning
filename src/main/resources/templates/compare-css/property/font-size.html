Pixels (px)

Absolute size that does not change if the user changes the root font-size.

font-size: 12px; (smaller)

font-size: 16px; (typical body)

font-size: 24px; (bigger)

Root-relative (rem)

Relative to the root (<html>) font-size, useful for consistent scaling.

font-size: 0.875rem;

font-size: 1rem; (base)

font-size: 1.5rem; (larger)

Parent-relative (em)

Relative to the font-size of the element itself or its parent.

Parent at 16px (1em = 16px).

Child at 1.25em (≈ 20px).

Child at 0.75em (≈ 12px).

Percent (%)

Also relative to the parent font-size, expressed as a percentage.

Parent at 16px.

75% of 16px (≈ 12px).

125% of 16px (≈ 20px).

Keyword: larger

Increases the font-size relative to the parent, using browser-defined steps.

Parent at 16px.

Child with font-size: larger;

Keyword: smaller

Decreases the font-size relative to the parent, using browser-defined steps.

Parent at 20px.

Child with font-size: smaller;
